I’ve been messing about with AI use cases for the past couple of weeks. Lot is going on there. But I think, just like the meme coin casino hype cycle. We are at the peak of AI too. But there are tangents of AI there somewhere:
1.⁠ ⁠Localised AI: so you can download LLMs on your computer and use it without the internet if you like. I’ve been playing with open source models, some I downloaded on my computer and some using APIs. It took me a while to familiarise myself with the set up and different models. They are not there completely like the ChatGPT experience, because of the LLM’s size and memory of your system but there is a lot of scope for personalisation, like integrations with other softwares, long term memory and most importantly they are free. 
2.⁠ ⁠⁠Automation: this is like the most hyped AI product; automating processes using AI. A lot of AI agencies are selling these apart from chatbots. From personal assistants to almost all basic functionalities. I set up a few for myself but I’m yet to close in on what I actually need agents for and it seems everyday there are new AI agents with more advanced functionalities. One assistant to manage emails, calendars, lead generation. Very interesting and entertaining space. Most influencers I think are making more from their Skool communities than selling these agents. But there is scope for specialisation still I think. 
3.⁠ ⁠⁠RAG (Retrieval-Augmented Generation): this is like a topic of its own and basically means you can build up your AI’s memory and then should be able to exchange and even merge information. You can use it for basic function like fetching relevant information for you from documents. Or feeding instructions to perform functions based on the context you’ve provided. I made a basic one for myself to test out. Have to make another one with a wider scope of context manipulation. The basic one right now works only within a line of context I give but someone figured a way around it for the RAG agent to be more robust, I 
have to make one for myself and test it. 
4.⁠ ⁠⁠Open source versus closed source: this is one of those spaces that I keep going down the rabbit hole of. Lol. Basically zero Ads, forget paying for software and decentralised social media. I think this is the direction we will be moving in. Obviously not anytime soon because monopolies will find a way to distract and keep the sheep into the present status quo. But it’s inevitable. Especially for people like us who don’t want to pay 200 to openAI for using their tech. Every software you can imagine has an open source GitHub repository that you can clone. Obviously you need some level of technical expertise but it’s easy to just ask ChatGPT or Claude to write your code or feed it the code and ask what it means, edit, change/iterate, copy and paste. I found myself doing this way too much. It is time consuming and so I think it’s more important to actually spend that time on what you’re trying to achieve instead of trying out different stuff and then going down that rabbit hole of figuring out the code. Too many times I keep finding myself trying to sort out small stuff instead of building an overall MVP. 

Tell me if you have come across something useful that is worth exploring. Or can have a real use case in your immediate circle/vicinity. I want to focus on something that can be sold. But with so many options available, it’s harder to decide what to focus on.  And I think there’s a fear of actually finishing something.

The intelligent chatbot is actually the easiest and most sold. It takes some back and forth with the client to understand what the customer is looking for but scheduling appointments or setting meetings is simple. The work is building the appropriate knowledge-base and user experience. If someone wants to buy for their business, it can be built.

he gap is closing fast. With some AI, you can’t tell. In my experience, the context setting is what I’m struggling with. Like if you build a bot for appointment setting, then it do only that in intelligent ways. Or you give it more functionalities and it will work within that. And like, I have to know what I should tell the agent to look for, it can’t be random and I can’t expect the AI to know what I want. Building the RAG agent is somewhat answer to this. But again most LLMs I find are built on this typical white nonsense limitations or analytical thinking. Like I’ve been trying to get AI to stop saying spiritual for everything and get with a certain line of academic thinking but there bias. Also again there are uncensored models, which are fun.

I was thinking about this. What we need to do first is to create this eco system for ourself first. And then, push as an offering. 

We must start by first asking ourself, what digital worker do I need, then create it, and then give similar cut paste solutions while giving a demo that is a working use case. 

One example is the social media agent that emails you content that it’s going to post for you. You reply approved and done its on all your platforms. Or reply with make these changes and it sends back revised content. 

Basically, it is the ease of use and user interface that is going to matter eventually.

One of the predictions is creating ‘digital workers’. These are agents designed to do tasks and share/co-work the workload. For example, a social media agent that posts on your behalf. Once set up, all you need to do is approve the content. These are more like understanding the basics of how you can use AI, and do an agency model. 
The other option is to create a Saas. 

My prediction with Deepseek is that now Desis and Chinese ground level is going to get in the game. Earlier these big LLM guys were dominating the game, now it’s open season for no to low-budget. And new models will start coming in with much better efficiency than the last wave of AI based software/apps/models.
