# Open Source, Self-Hostable, Sustainable
## Overview
The one-vault system is **open source infrastructure for trust**. Anyone can clone it, host it, modify it. We also run a hosted version for convenience.

**Philosophy:** 
- Software is free (open source)
- Hosting convenience is paid (optional)
- Users choose: DIY or managed
- Never lock-in, never extraction

**Model:** Like n8n, Supabase, Ghost - open core with managed hosting.

---

## A. Two Ways to Use OVS

### Option 1: Self-Host (Free Forever)

**What You Get:**
- ✅ Full source code (Apache 2.0)
- ✅ Unlimited users, circles, shares
- ✅ All features (no restrictions)
- ✅ Complete control
- ✅ No payment ever

**Requirements:**
- VPS server (~₹300-500/month)
- Basic Linux skills
- ~2 hours setup, ~1 hour/month maintenance

**Support:**
- Community forum
- Documentation
- GitHub issues

**Who Should Self-Host:**
- Tech-savvy users
- Organizations with IT teams
- Privacy-focused communities
- Those wanting full control

---

### Option 2: Cloud Hosted (Freemium)

**Why Pay Us:**
- We manage infrastructure
- Automatic updates
- Automatic backups
- Email support
- Mobile apps
- 99.9% uptime

**You Pay For:** Convenience, not software

## C. Core Principles

### What We Will NEVER Do

**1. Lock You In**
- ❌ Never close the source code
- ❌ Never prevent data export
- ❌ Never restrict self-hosting
- ❌ Never paywall core features

**2. Extract Value**
- ❌ Never transaction fees
- ❌ Never sell user data
- ❌ Never hidden costs
- ❌ Never dark patterns

**3. Compromise Mission**
- ❌ Never interest-based features
- ❌ Never Islamic compliance paywalls
- ❌ Never VCs that conflict with values
- ❌ Never sell to unaligned buyers

## J. Key Comparisons

### n8n Model (Our Inspiration)

```
Similar:
✓ Open source core
✓ Self-hostable
✓ Cloud convenience option
✓ Enterprise tier

Different:
• n8n: Fair-code license
• bzkt: Full Apache 2.0
• n8n: B2B automation
• bzkt: Community finance
```

### Our Unique Angle

**Open source builds trust → Trust attracts users → Some pay for convenience → Revenue funds development → Better platform → More trust**

This virtuous cycle works for infrastructure products. bzkt is infrastructure for trust.

## Summary

**The n8n Model Applied to Islamic Finance:**

- **Open source** (anyone can see, fork, self-host)
- **Cloud hosted** (we manage for convenience)
- **Freemium** (free tier genuinely useful)
- **Premium** (extras, not core features)
- **Enterprise** (white-label, support, integrations)
- **Sustainable** (₹20L/year target by Year 5)
- **Mission-locked** (can't be sold out)

**The Exchange:**
- Self-hosters get: Free software forever
- Cloud free users get: Free hosted version
- Cloud paid users get: Convenience + extras
- We get: Sustainable business
- Everyone gets: Trust infrastructure for Islamic finance

**Result:** Sustainable, ethical, mission-driven business that serves the one-vault economy without exploitation.
